# Smart Railway Resource Planning System

## Problem
Railways require better planning for trains, platforms, and coaches.

## Solution
This project predicts passenger demand using machine learning and recommends coach allocation.

## Features

Passenger demand prediction  
Interactive Streamlit dashboard  
Coach recommendation system  
Data visualization

## Tech Stack

Python  
Scikit-learn  
Streamlit  
Pandas  

## Run Project

pip install -r requirements.txt

streamlit run app.py
